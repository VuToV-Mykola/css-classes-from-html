```
backend/
├── core/
│   ├── IntegrationEngine.js      # Головний двигун інтеграції

│   ├── FigmaAnalyzer.js          # Аналізатор Figma макетів

├── matchers/
│   ├── StyleMatcher.js           # Система співставлення стилів
│   └── HierarchyMatcher.js       # Ієрархічне співставлення
├── generators/
│   ├── CSSGenerator.js           # Базовий CSS генератор
│   └── SimplyChocolateCSSGenerator.js # Спеціалізований генератор
└── utils/
    └── ValidationSystem.js       # Система валідації
```

## 🚀 Ключові функції

### 1. Simply Chocolate Integration
- **Аналізатор макету**: Детальний аналіз структури, кольорів, типографіки
- **CSS генератор**: Спеціалізований генератор з Simply Chocolate темою
- **Компоненти**: Product cards, buttons, navigation, forms
- **Адаптивність**: Mobile-first підхід з breakpoints

### 2. Розширена система співставлення
- **7 стратегій**: Content-based, Structural, Semantic, Positional, Hierarchical, ML-based
- **ML алгоритми**: Cosine similarity, Levenshtein distance
- **Впевненість**: Розрахунок confidence score для кожного співставлення
- **Fallback**: Автоматичне співставлення для невідповідних елементів

### 3. Система валідації
- **5 валідаторів**: HTML, Figma, CSS, Matching, Responsive
- **Оцінка якості**: Загальна оцінка з градацією A-F
- **Рекомендації**: Автоматичні рекомендації для покращення
- **Звіти**: Детальні JSON звіти з статистикою

### 4. VSCode команди
- `css-classes.generateSimplyChocolateCSS` - Генерація CSS
- `css-classes.analyzeSimplyChocolate` - Аналіз макету
- `css-classes.validateSystem` - Валідація системи
