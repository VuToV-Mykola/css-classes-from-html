# 🤖 ДОКУМЕНТАЦІЯ ДО СКРИПТІВ CSS CLASSES FROM HTML v0.0.7

## 📋 ОГЛЯД СКРИПТІВ

Проект містить потужну систему автоматизації, що складається з декількох взаємопов'язаних скриптів у теці `scripts/`:

### 🚀 **project-manager.sh** - Головний інтерактивний менеджер
- Центральний інструмент управління проектом
- Красива візуалізація та інтерактивні меню
- Об'єднує всі скрипти в одному інтерфейсі
- Статистика проекту в реальному часі

### 🤖 **auto-generate-docs.sh** - Автогенератор документації
- Аналізує структуру проекту  
- Зберігає перші 37 рядків з існуючих README
- Генерує новий контент з рядка 38
- Підтримка 3 мов: українська, англійська, німецька

### 📦 **deploy.sh** - Скрипт розгортання
- Валідація коду та виправлення помилок
- Створення VSIX пакету
- Публікація в VS Code Marketplace
- Git операції та версіонування

### 🧪 **test_extension.sh** - Автоматизоване тестування
- Повний цикл тестування розширення
- Встановлення та видалення в VS Code
- Генерація детального звіту
- Мануальне та автоматизоване тестування

## 🎯 ШВИДКИЙ СТАРТ

### 1. Запуск головного менеджера
```bash
./scripts/project-manager.sh
```

### 2. Автогенерація документації
```bash
./scripts/auto-generate-docs.sh
```

### 3. Тестування розширення
```bash
./test_extension.sh
```

## 🚀 РОЗШИРЕННЯ ФУНКЦІОНАЛЬНОСТІ

### Додавання нового скрипту:
1. Створити скрипт у теці `scripts/`
2. Додати до масиву `scripts` у `project-manager.sh`
3. Створити відповідний пункт меню
4. Додати функцію обробки
5. Оновити документацію

### Локалізація:
Для додавання нової мови до автогенератора:
1. Створити функцію `generate_LANGUAGE_content()`
2. Додати виклик у `generate_documentation()`
3. Оновити `get_readme_header()` для нового файлу
